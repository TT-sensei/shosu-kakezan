# 小数のかけ算

5年生の「小数 × 小数」を、スモールステップで確認しながら練習する算数教材です。
「小数のたし算・ひき算」（shosu4nen）と同じ作りで、見当 → 筆算 → 小数点の位置の確認、の順に進めます。

公開ページ： https://tt-sensei.github.io/shosu-kakezan/

## 学習の流れ（1問の進み方）

1. **見当**：計算の前に、答えのだいたいの大きさを選ぶ。見当違いは間違いとして記録しない。
2. **筆算**：小数点をないものとして整数のかけ算をする。部分積（かけ算）と、その合計（たし算）を、位ごとに1桁ずつ入力し、くり上がりを表示しながら進める。
3. **小数点の位置の確認（独立したステップ）**：
   - 2つの数それぞれの「小数点以下のけた数」を子ども自身が数える（例：2.3 は1けた、1.4 は1けた）。
   - 合わせたけた数を確認する（1＋1＝2けた）。
   - 筆算で出た整数の数字の列に、右からそのけた数だけ数えた位置をタップして小数点を打つ。
   - 末尾の0を消す場合・答えが整数になる場合は、その形に直して最終の答えを示し、見当と合っているかを表示する。
4. 正解・不正解のフィードバックはその場で出る。途中でつまずいた段階（筆算／けた数／小数点の位置）を問題ごとに記録する。

間違えた問題は「とっくん」に記録され、正解すると記録から外れます（克服）。とっくんに敵・HP・タイマーはありません。
練習結果では、最初からノーミスで解けた問題と、途中で直した問題を区別して表示します。

## 問題の種類（各10問・自動生成）

| 種類 | 内容 | 案内役 |
| --- | --- | --- |
| ふくしゅう：小数 × 整数 | 小数第1位・第2位 × 1桁の整数（4年生の復習） | りく |
| 小数第1位 × 小数第1位 | 2.3 × 1.4 のような基本の小数 × 小数 | つき |
| 小数第2位 × 小数 | 0.25 × 1.6、3.14 × 2.6 など | かい |
| ミックス チャレンジ | 上記の混合 | さく |

「小数第1位 × 小数第1位」「小数第2位 × 小数」「ミックス」の10問には、次のつまずきやすい型が必ず1問ずつ入ります。

- **答えが整数になる型**（例：2.5 × 0.4 ＝ 1）
- **末尾の0を消す型**（例：1.5 × 0.4 ＝ 0.60 → 0.6）
- **0を補う型**（例：0.2 × 0.3 ＝ 0.06、0.12 × 0.3 ＝ 0.036）

問題は練習のたびに自動生成されます（同じ回の10問の中で同じ式は出しません）。

## 保存（この端末のブラウザー内のみ）

- `shosuKakezan.mistakes.v1`：間違えた問題と、つまずいた段階（hissan／keta／point）
- `shosuKakezan.stats.v1`：種類ごとの実施数とノーミス数
- `shosuKakezan.settings.v1`：音のON/OFF

## 技術・利用

- HTML / CSS / JavaScriptで動作する静的な教材です。外部API・外部CDN・外部フォントは使いません。
- 音は sounds-recipe-、演出のCSSは edu-effects、キャラクター画像は navi-character の自前共通基盤を利用します（読み込めなくても学習は続けられます）。
- 学習記録は利用端末のブラウザー内に保存します。サーバー側データベースは使用しません。
